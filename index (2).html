1. Introduction & Learning Objectives

NodeMCU is an open-source IoT development board built around the ESP8266 Wi-Fi SoC (usually the ESP-12E/F module). The name originally referred to its Lua firmware, but today it mostly means the board. It is programmed with the Arduino IDE (C/C++), MicroPython or Lua.

Operating principle: a 32-bit CPU runs your program from external SPI flash; the integrated 2.4 GHz radio and TCP/IP stack let it join a Wi-Fi network (or create one), while GPIO, PWM, ADC, I²C, SPI and UART interface to sensors and actuators. A USB-UART bridge and a 3.3 V regulator make it plug-and-play.

Why it matters: low-cost Wi-Fi connectivity with almost no extra hardware makes it a standard tool for IoT prototyping, home automation and data logging.

Prerequisites: voltage dividers, Ohm's law, digital logic levels, basic C programming, serial communication basics.

Terminology: SoC – CPU + radio + peripherals on one chip. Station (STA) – joins an existing router. Soft-AP – board hosts its own network. Strapping pin – pin sampled at reset to choose boot mode. PWM – pulse-width modulation. MQTT – lightweight publish/subscribe protocol. OTA – over-the-air firmware update.

Classification of related boards: NodeMCU ESP-12E (ESP8266, v1.0), Wemos D1 mini (ESP8266, compact), NodeMCU-32S / ESP32 DevKit (dual-core, Wi-Fi + Bluetooth).

4. Working Principle & Detailed Explanation

  1. Power-up: USB 5 V → LDO → 3.3 V. At reset the chip samples GPIO0, GPIO2, GPIO15 to pick the boot mode.
  2. Normal boot: GPIO15 = LOW, GPIO0 = HIGH, GPIO2 = HIGH → boot from SPI flash. GPIO0 = LOW → UART download (flashing) mode.
  3. Execution: your program runs; the Wi-Fi stack runs in the background, so long blocking code (≈ >3 s without yield()/delay()) triggers the watchdog and a reset.
  4. Connectivity: WiFi.begin(ssid, pass) joins a router (station). Soft-AP mode creates a hotspot; both can run together. Then use ESP8266WebServer or MQTT (PubSubClient).
  5. I/O: GPIO outputs 3.3 V logic; analogWrite() gives software/hardware PWM (default 0–1023); analogRead(A0) returns 0–1023.

DC vs RF behaviour: DC supply must carry Wi-Fi transmit bursts of about 170–300 mA; the weak point is usually the USB cable/supply, not the average current.

Setup flow (Arduino IDE): install ESP8266 board package → select “NodeMCU 1.0 (ESP-12E Module)” → choose COM port → upload.

Advantages / limitations

Advantages: cheap; built-in Wi-Fi; Arduino ecosystem; OTA updates; deep-sleep support.
Limitations: 3.3 V only; one 10-bit ADC; few usable GPIOs; strapping-pin constraints; limited RAM; no Bluetooth; 2.4 GHz only.

Common misconceptions

  • “Wi-Fi works at 5 GHz” – no, 2.4 GHz only.
  • “GPIOs tolerate 5 V” – no; use dividers/level shifters.
  • “A0 reads 0–3.3 V on any ESP8266” – only on boards with the onboard divider; the bare chip reads 0–1 V.
  • “All pins are free” – D3, D4, D8 (and D0 for some functions) have constraints.

6. Key Equations

(a) Voltage divider (ADC input scaling)

Vpin = Vin · R2 / (R1 + R2)

Derivation: series current I = Vin/(R1+R2); Vpin = I·R2. Valid when the load (ADC) draws negligible current. Onboard divider: R1 = 220 kΩ, R2 = 100 kΩ → Vpin = Vin/3.2, so Vin,max = 3.2 V for a 1 V chip range.

(b) ADC code and resolution

N = floor( Vpin / Vref × 210 ), LSB = Vref / 1024 ≈ 0.98 mV (Vref = 1 V)

N is the code (0–1023), Vref the 1 V full-scale. At the board input the LSB is ≈ 3.2 × 0.977 ≈ 3.1 mV. Physical meaning: smallest resolvable change.

(c) PWM

D = NPWM / 1023, Vavg = D · VDD (VDD = 3.3 V), T = 1/f

D is the duty cycle (unitless), applicable to resistive/filtered loads. Limits: D = 0 → 0 V, D = 1 → 3.3 V.

(d) LED current-limiting resistor

R = (VGPIO − VF) / ILED

Keep GPIO current at or below ~12 mA (absolute maximum per pin).

(e) UART timing (8N1 = 10 bits per byte)

tbyte = 10 / baud, tN = 10N / baud

(f) I²C timing

t = (9 × bytes) / fSCL (ignoring START/STOP; 8 data bits + 1 ACK per byte)

(g) Power and battery life

P = V·I,   E = P·t,   Iavg = (Iactive·ta + Isleep·ts)/(ta+ts),   Life(h) = Capacity(mAh) / Iavg(mA)

(h) Decibel (for Wi-Fi RSSI)

P(dBm) = 10·log10( P / 1 mW )

7. Solved Numerical Problems

Problem 1 (Easy) – ADC reading. On a NodeMCU (220 kΩ/100 kΩ divider, Vref = 1 V), analogRead(A0) returns 512. Find Vin.
Required: Vin. Formula: Vpin = N/1024 × 1 V; Vin = Vpin × (R1+R2)/R2.
Vpin = 512/1024 × 1 V = 0.5 V. Vin = 0.5 × (320 kΩ/100 kΩ) = 1.6 V.
Interpretation: mid-scale code corresponds to half of the 3.2 V full range.
Problem 2 (Easy–Moderate) – LED resistor. GPIO = 3.3 V, VF = 2.0 V, desired I = 5 mA.
R = (3.3 − 2.0) V / 5 mA = 1.3 / 0.005 = 260 Ω → choose standard 270 Ω.
Actual I = 1.3 / 270 = 4.81 mA (< 12 mA limit). Interpretation: rounding up to the next standard value keeps current safe.
Problem 3 (Moderate) – PWM average. analogWrite(pin, 256) at VDD = 3.3 V.
D = 256/1023 ≈ 0.2502 (≈ 25%). Vavg = 0.2502 × 3.3 ≈ 0.83 V.
Interpretation: an RC filter on the pin would output ≈ 0.83 V DC.
Problem 4 (GATE-style, Difficult) – Sleep-mode average current. A node is active at 80 mA for 2 s, then deep-sleeps at 20 µA for 58 s, repeating every 60 s. Find Iavg and the life with a 2000 mAh battery.
Iavg = (80 × 2 + 0.02 × 58)/60 = (160 + 1.16)/60 = 2.686 mA. Life = 2000/2.686 ≈ 745 h ≈ 31 days (ideal, ignoring regulator/battery losses).
Shortcut: the active phase dominates, so Iavg ≈ Iactive × duty (here 80 × 1/30 = 2.667 mA); sleep adds only ~0.02 mA.
Problem 5 (Moderate) – UART time. Sending 100 bytes at 115200 baud (8N1): bits = 100 × 10 = 1000; t = 1000/115200 = 8.68 ms.

Quick revision notes & high-priority points

  • 3.3 V logic, not 5 V tolerant; 2.4 GHz only; one 10-bit ADC (chip 0–1 V).
  • Normal boot: GPIO15 LOW, GPIO0 HIGH, GPIO2 HIGH. GPIO0 LOW = flash mode.
  • Deep-sleep wake: GPIO16 → RST. Onboard LED (GPIO2) is active-low.
  • Wi-Fi TX bursts 170–300 mA → good supply + bulk capacitor.
  • For more analog channels use 74HC4051 (mux) or ADS1115 (16-bit I²C ADC).

Memory aids

  • “15 low, 0 and 2 high” → boots from flash.
  • 8N1 = 10 bits, not 8, per byte.
  • I²C = 9 clocks per byte (8 + ACK).
